# 视频来源与核验记录

原课程：蒋炎岩，南京大学《生成式软件工程》2026 年第 3 讲。

原视频：<https://www.bilibili.com/video/BV1kybV6DE47/>

本目录保存本次实际运行的媒体完整性报告、音频窗口字幕、12 张配图的原始帧与裁剪记录、逐 5 分钟主题覆盖审查及讲义主张核验记录。原视频、音轨、模型和全部候选帧保留本地，未上传。

`audio_raw.srt` 为本地 SenseVoice 自动转录，时间戳表示真实的 20 秒输入窗口，**不是逐字对齐时间**。它会把 Git、GitHub 等英文术语识别错，因此可用于定位和辅助审查，不宜未经校对直接当作准确引文。原始文字保持不变。

`source-verification.json` 的 PASS 表示媒体哈希与时长、转录窗口处理、配图出处、已记录的主题覆盖审查均通过；不代表每个字或每一帧已经人工核对。`content_review.json` 明确记录审查范围。
